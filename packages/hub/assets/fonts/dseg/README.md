# DSEG

Vendored DSEG font files for the VFD Amber theme.

- Source: https://github.com/keshikan/DSEG
- Files kept:
  - `DSEG7Classic-Italic.ttf`
  - `DSEG14Classic-Italic.ttf`
  - `LICENSE.txt`
- License: SIL Open Font License 1.1

DSEG7 draws readings as seven-segment digits and DSEG14 draws units and titles
as fourteen-segment characters, the same faces the InfoPanel VFD profiles and
the VFD Clock keys use.
